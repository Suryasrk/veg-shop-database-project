# 🥕 Vegetable Shop Management System

A **Python-based Command Line Application** for managing a vegetable shop, integrated with a **MySQL database**.  
The system helps shopkeepers manage inventory, handle customer purchases, track sales, and calculate profits efficiently.

---

## 📌 Project Overview

The Vegetable Shop Management System is designed to automate daily shop operations such as:
- Managing available vegetables and stock
- Handling customer purchases and carts
- Recording sales transactions
- Calculating profits (item-wise, daily, and overall)

The application runs in the terminal and uses **MySQL** as the backend for persistent data storage.

---

## 🚀 Features

### 👤 User Management
- Customer and Shopkeeper login system
- Role-based access to functionalities

### 🥬 Inventory Management
- View available vegetables
- Check price and quantity
- Update stock (shopkeeper)

### 🛒 Cart & Sales
- Add vegetables to cart
- Generate bills
- Store sales records in database

### 📈 Profit Analysis
- Item-wise profit calculation
- Daily profit tracking
- Total profit summary

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **Database:** MySQL  
- **Library Used:** `pymysql`  
- **Interface:** Command Line (CLI)
